クラス

朝に二つ、昼に二つ、夜に二つ。動きの多いものから、ほとんど動かないものまであります。その日のからだに合わせて選んでください。

呼吸舎の一日

出勤前、昼休み、仕事のあと。朝から夜まで、六つのクラスがあります。どのクラスも定員は十二名、予約制です。

朝すっきりと、
一日のはじまりを。

寝起きのこわばったからだを、ゆっくり起こす時間です。終わってから出勤に間に合います。

7:00〜8:00・60分

モーニングフロー

呼吸に合わせて、とぎれずに動きます。吸いながら伸び、吐きながらたたむ。その繰り返しで、少しずつからだが温まっていきます。

動きの強さ
中くらい。後半はうっすら汗をかきます。
向いている方
朝のうちに一度からだを動かしておきたい方。何回かヨガをしたことがある方。
すること
座って呼吸を数える → 四つんばいで背中を動かす → 太陽礼拝をゆっくり五回 → 立つポーズ → 仰向けで休む（5分）
開催日
月・火・水・木・金
担当
小野 遥

9:00〜10:00・60分

やさしいハタヨガ

基本のポーズを、ひとつずつ丁寧に。動きと動きのあいだに休む時間があるので、説明を聞きながら自分の速さで進められます。

動きの強さ
弱め。息が上がることはほとんどありません。
向いている方
はじめての方、久しぶりの方。体験クラスで迷ったら、まずこのクラスを。
すること
呼吸の練習 → 首・肩・股関節をほぐす → 立つポーズと座るポーズを六つほど → 仰向けで休む（8分）
開催日
月・水・金・土・日
担当
田中 美咲

昼ひと息ついて、
午後のわたしへ。

座りっぱなしで固まった肩と腰を、動かしてほぐします。昼休みにも通える長さです。

12:00〜12:45・45分

リフレッシュヨガ

デスクワークの合間に、短く集中して。汗をかかない程度の動きなので、着替えてそのまま午後の仕事に戻れます。

動きの強さ
弱め。汗はほとんどかきません。
向いている方
昼休みに通いたい方。肩や腰のこわばりが気になる方。
すること
肩まわりを大きく動かす → 背骨を前後・左右にひねる → 股関節を開く → 座って呼吸を整える（3分）
開催日
月・火・水・木・金
担当
森 拓海

14:00〜15:00・60分

コンディショニングヨガ

立ち姿勢と体幹を、じっくり使います。六つのなかでは、いちばんしっかり動くクラスです。きついポーズには、らくな形も用意しています。

動きの強さ
強め。脚とお腹まわりを使い、汗をかきます。
向いている方
しっかり動きたい方。やさしいクラスに慣れて、もう一歩進みたい方。
すること
からだを温める → 戦士のポーズなど立つポーズを長めに保つ → 板のポーズなど体幹の動き → 仰向けで休む（5分）
開催日
火・木・土・日
担当
小野 遥

夜静けさのなかで、
一日をほどく。

照明を落として、動きは少なめに。仕事帰りにそのまま寄れる時間です。

18:30〜19:45・75分

やさしい陰ヨガ

ひとつの姿勢を三分から五分ほど保ち、力を抜いていきます。クッションやブロックでからだを支えるので、がんばって形をつくる必要はありません。

動きの強さ
ごく弱め。ほとんど動かず、床に近い姿勢で過ごします。
向いている方
動くより、じっとしていたい日の方。からだがかたい方にも向いています。
すること
座って呼吸を数える → 床に座る・寝る姿勢を六つほど、それぞれ長く保つ → 仰向けで休む（10分）
開催日
月・水・金
担当
田中 美咲

20:00〜21:00・60分

ナイトリラックスヨガ

寝ころぶ姿勢が中心の、静かなクラス。部屋のあかりは手もとが見える程度まで落とします。最後は毛布をかけて、長めに休みます。

動きの強さ
ごく弱め。立つポーズはありません。
向いている方
仕事のあと、頭を休めてから帰りたい方。はじめての方も参加できます。
すること
仰向けで呼吸を感じる → 寝たまま脚や背中をゆっくり伸ばす → 長く吐く呼吸の練習 → 仰向けで休む（12分）
開催日
火・木・金
担当
森 拓海

クラスの選び方

はじめてなら
9:00 のやさしいハタヨガか、20:00 のナイトリラックスヨガを。説明の時間が長く、動きもゆっくりです。
疲れている日は
夜の二つのクラスを。ほとんど床の上で過ごします。途中で眠ってしまってもかまいません。
しっかり動きたい日は
7:00 のモーニングフローか、14:00 のコンディショニングヨガを。
時間がない日は
12:00 のリフレッシュヨガを。着替えを入れても、一時間ほどで出られます。

どのクラスも、開始の10分前から部屋に入れます。開始後の入室は、安全のため10分までとしています。

まずは一度、呼吸をしに。
